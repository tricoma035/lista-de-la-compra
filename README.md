# Aplicación Web de Filtrado de Productos Alimenticios 

## 1. Descripción General

Construir una aplicación web cliente-servidor cuyo propósito principal es ayudar a los usuarios con intolerancias alimentarias, alergias o preocupaciones sobre ingredientes específicos a identificar rápidamente si un producto alimentario envasado es apto o no para su consumo. La aplicación debe permitir al usuario seleccionar sus intolerancias (inicialmente: fructosa, lactosa, sacarosa y gluten, con posibilidad de futuras ampliaciones a otras intolerancias y alergias) y luego, al buscar un producto, mostrar si es compatible con sus restricciones dietéticas, informando y proponiendo alternativas si es posible. Se debe priorizar la claridad, la facilidad de uso, la accesibilidad y la precisión en la información proporcionada.
